# 보고서 작성

숫자가 틀리지 않고, AI가 쓴 티가 나지 않고, 표가 사람이 만든 것처럼 보이는 한국어 문서를 만드는 절차다.
규칙 원문은 `${CLAUDE_PLUGIN_ROOT}/skills/report/references/`에 있다. 문서를 쓰기 전에 두 파일을 읽는다.

- `워딩규칙.md`: 금지 표현, 문체, 표식, 외부 제출 파일 규칙
- `표서식규칙.md`: Word와 엑셀 표 서식, 마크다운 표 입력 문법

## 절차

1. **목적과 독자를 정한다.** 누가 읽는지(대표, 투자자, 팀, 거래처), 무엇을 결정하게 할 문서인지, 분량. 사용자가 말하지 않았으면 맥락으로 정하고 첫 줄에 적어 확인받는다.

2. **숫자부터 확인한다.** 쓸 숫자를 원천(엑셀, PDF, 메일)에서 찾아 작업 원고에 `(출처: 파일 p.N)` 또는 `(출처: 파일 시트!셀)`로 붙인다. 원천에 없으면 만들지 않고 `[확인 필요: 무엇]`으로 둔다. 계산한 숫자는 계산식을 남긴다.

3. **초안을 마크다운으로 쓴다.** 기본 틀:
   - 제목과 한 줄 요약(결론 먼저)
   - 본문: 현황, 원인, 영향, 대응 순. 한 문단 3~5문장, 서술식 경어체
   - 표: `[표 제목]`, `(단위: …)` 줄을 표 위에. 합계는 `**굵게**`, 음수는 `(1,234)`
   - 표 아래 주석은 `주1)`로
   - 맨 끝에 「확인이 필요한 사항」 목록(남은 `[확인 필요]` 모음)

4. **스스로 점검한다.** 저장하면 플러그인 훅이 금지 표현을 찾아 알려 준다. 알림이 오면 고치고 다시 저장한다. 따로 돌릴 때:
   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/doc_check.py" 초안.md
   ```

5. **문장을 다듬는다(선택).** 외부로 나가는 문서이거나 사용자가 원하면 wording 스킬로 코덱스에게 문장 다듬기를 맡긴다. 코덱스가 설치되지 않았으면 이 단계는 건너뛰고 그렇게 알린다. 숫자가 하나라도 바뀐 결과는 쓰지 않는다.

6. **Word로 만든다.** 표가 있으면 표 서식 엔진, 없으면 간단 변환기:
   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/skills/report/scripts/md2docx_table.py" 문서.md 문서.docx
   python3 "${CLAUDE_PLUGIN_ROOT}/skills/report/scripts/table_render.py" 문서.docx 렌더     # 표를 PNG로
   # 표 없는 짧은 문서: md2docx_simple.py 문서.md 문서.docx
   ```
   변환 결과 끝에 「원천 표기 잔존 0건」, 「기본 정보 접힘 0건」이 나와야 한다. 렌더한 PNG를 직접 열어 잘린 숫자, 접힌 이름이 없는지 본다.
   - 머리행이 「출처」, 「근거」인 열은 docx에서 자동으로 빠진다.
   - 표 서식 엔진: `[확인 필요: …]`, `[작성 대기: …]`는 노란 형광, `[메모: …]`는 Word 메모가 된다.
   - 간단 변환기: 대괄호 `[ ]` 안 글자를 모두 노란 형광으로 칠한다(계약서 공란 `[○○○]` 등).
   - 필요한 패키지: `python3 -m pip install --user python-docx pillow`

7. **엑셀이 필요하면** `표서식규칙.md` 3절(외부 제출용 엑셀) 서식으로 만든다. 숫자는 가능하면 수식으로 남기고, 내부 검증 시트는 별도 파일로 뗀다.

8. **보고한다.** 짧게 세 묶음: 만든 것(파일 경로), 그대로 둔 것, 사용자가 판단하거나 채울 것(노란 칸 목록). 실수가 있었으면 맨 앞에 말한다.

## 사용자가 Word에서 직접 고친 뒤

사용자가 docx를 고치기 시작하면 그 파일이 새 원본이다. 마크다운에서 다시 만들지 않는다. 지시받은 칸과 문단만 python-docx로 직접 고치고, 바꾼 곳마다 전후 글자를 나란히 보여 준다.

## 하지 않는 것

- 원본에 없는 숫자, 사실, 전망을 만들지 않는다.
- 폭이 모자란다고 표 글자부터 줄이지 않는다(표서식규칙 2절 7번 순서).
- 메일 발송, 업로드처럼 밖으로 나가는 일은 사용자 확인 없이 하지 않는다.
