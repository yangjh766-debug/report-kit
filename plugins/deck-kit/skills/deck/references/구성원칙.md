# 구성 원칙: 결론 먼저, 장 제목으로 이어지는 이야기

컨설팅 파트너가 짜는 덱처럼, 읽는 사람이 장 제목만 넘겨 봐도 결론과 근거를 따라올 수 있게 만든다.

## 1. 이야기 구조

- **결론을 맨 앞에.** 표지 다음 장은 한 장 요약이다. 왼쪽에 전체 결론 한 문장, 오른쪽에 그 결론을 받치는 숫자 세 개.
- **장 제목 = 그 장의 결론.** 주제 이름("매출 현황")이 아니라 숫자가 든 완결 문장("2027년까지 늘어날 매출 300억원의 60%를 신사업이 만듭니다")으로 쓴다. 15~35자.
- **부제 = 제목의 근거 숫자 한 줄.** 제목과 같은 말을 되풀이하지 않는다.
- **장 하나에 메시지 하나.** 하고 싶은 말이 둘이면 장을 나눈다.
- **장 제목만 이어 읽기 점검.** 다 만든 뒤 제목만 뽑아 위에서 아래로 읽는다. 논리가 끊기거나 같은 말이 반복되면 순서를 바꾼다.
- **구간 구성(IR 덱 기본):** 회사 → 성장 → 사업 구조와 경쟁력 → 확장 → 투자(밸류에이션, 조건, 자금 사용) → 맺음.

## 2. 리듬: 핵심 장표와 증거 장표

| 종류 | 엔진 함수 | 언제 |
|---|---|---|
| 숫자 하나 | `heroNumber` | 가장 센 숫자(목표 매출, 핵심 성과). 다음 장 차트로 모핑 |
| 전면 사진 | `heroPhoto` | 현장, 제품, 고객 장면으로 숫자에 실감을 줄 때 |
| 한 문장 | `heroQuote` | 고객 인터뷰, 수주 이유처럼 주장 하나 |
| 표지, 맺음 | `cover`, `closing` | 시작과 끝 |

- 핵심 장표는 4~6장마다 하나. 빽빽한 증거 장 사이에 숨 쉬는 장이 있어야 둘 다 강해진다.
- 증거 장표는 결론에 맞는 그림을 고른다: 추이는 `trend`, 증감 분해는 `bridge`, 계획 대비는 `planRows`, 단계별 현황은 `pipeline`, 비교는 `barsH`, 구성 변화는 `shareBars`, 핵심 지표는 `kpis`.

## 3. 숫자 해석 (PE, FAS 관점)

원천 숫자에서 계산하고, 계산식을 각주에 적는다. 회사에 맞는 것만 고른다.

| 지표 | 계산 | 투자자가 읽는 뜻 |
|---|---|---|
| 연평균 성장률 | (끝 값 / 시작 값)^(1/년수) − 1 | 성장 속도 |
| 이익률 변화 | 연도별 영업이익 / 매출 | 규모의 경제가 생기는지 |
| 매출 구성 변화 | 사업별 매출 / 전체 | 특정 사업 의존도, 다각화 |
| 증감 분해(다리형) | 기간 증가분을 원인별로 | 성장을 무엇이 만드는지 |
| 단위 경제성 | 단위(고객, 도시, 매장)당 매출, 이익, 회수 기간 | 늘릴수록 돈이 되는 구조인지 |
| 매출의 질 | 계약, 선수금, 반복 매출 비중, 이탈률 | 숫자가 얼마나 확실한지 |
| 현금 전환 | 선지급, 운전자본, 회수 구조 | 성장에 돈이 얼마나 묶이는지 |
| 배수 | 기업가치 / 순이익(PER), 매출, ARR, EBITDA | 비교 기업 대비 가격 |
| 주의할 점과 대응 | 인식 시점, 집중도, 원가 구조 | 리스크를 알고 있다는 신호 |

- 외부 시장 규모, 점유율처럼 근거가 없는 숫자는 쓰지 않는다. 비교 기업 배수는 출처가 있을 때만.
- 계획 숫자와 실적 숫자를 섞지 않고, 장마다 기준(실적, 전망 E, 계획 P)을 각주에 밝힌다.
- 원천끼리 숫자가 다르면 임의로 맞추지 않고 각 장의 원천 숫자를 쓴 뒤 사용자에게 목록으로 알린다.

## 4. 점검표

- [ ] 표지 다음에 한 장 요약이 있다
- [ ] 모든 장 제목이 숫자가 든 결론 문장이다
- [ ] 장 제목만 이어 읽어도 논리가 이어진다
- [ ] 핵심 장표가 4~6장마다 있다
- [ ] 계산한 숫자마다 각주에 계산식이 있다
- [ ] 근거 없는 외부 숫자가 없다
