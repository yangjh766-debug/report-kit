# 카피 규칙: 덱 문구

보고서 문장처럼 "자연스럽게"가 목표가 아니다. 한 문장 한 문장이 그 장의 결론과 함의를 담고, 실무 전문가가 쓴 말투여야 한다.

## 1. 역할별 기준

| 역할 | 기준 | 길이 |
|---|---|---|
| 장 제목 | 그 장의 결론. 사실이 아니라 사실이 뜻하는 바 | 15~35자 |
| 핵심 문구(검은 화면, 전면 사진) | 한눈에 읽히는 선언. 두 줄 이내 | 줄당 6~12자 |
| 부제 | 제목을 받치는 숫자 근거 한 줄 | 한 줄 |
| 설명 | 무엇을 얻는지가 보이게. 두 줄 이내 | 줄 수 고정 |
| 각주 | 꾸미지 않는다. 기준과 계산식 | 두 줄 이내 |

## 2. 문장을 고르는 법

- 늘이지 않는다. 단순히 줄이지도 않는다. 같은 길이 안에서 더 많은 의미가 실리는 단어를 고른다.
- 결과를 앞에 둔다. "당사는 ~를 통해 ~하고 있습니다"가 아니라 "~가 ~이 됩니다".
- 힘 빠지는 말을 지운다: ~하고 있습니다, ~할 수 있습니다, ~를 통해, ~를 기반으로, 다양한, 효율적인, 지속적인, 솔루션, 역량 강화.
- 함의는 숫자와 사실에서만 끌어낸다. 최고, 유일, 압도적, 혁신적 같은 과장은 쓰지 않는다.
- 한 장 안에서 제목과 부제가 같은 말을 되풀이하지 않는다.

## 3. 구어체와 비유를 실무 용어로

| 쓰지 않는 말 | 대신 |
|---|---|
| 완주, 정복, 석권 | 개최 완료, 진출, 점유 |
| 순회, 돌린다 | 투어, 도시 확장, 반복 운영 |
| 다시 팔아, 또 팔면 | 반복 판매해, 추가 판매 시 |
| ~만 700만 달러입니다(강조 '만') | 700만 달러를 확보했습니다 |
| 이만큼, 이렇게나 | 숫자를 직접 쓴다 |
| 일곱 갈래, 여러 갈래 | 일곱 가지, 일곱 개 영역 |
| 확 늘었다, 폭발적, 대박 | 전년 대비 ○○% 증가 |
| 남는 게 많다 | 매출총이익률 ○○% |
| 먹힌다, 통한다 | 검증했다, 성과를 냈다 |
| 이식, 막는다, 차단 | 옮기기, 걸러낸다, 멈춘다 |

## 4. 표기

- 가운뎃점(·), 화살표(→), 줄표(—)로 문장을 잇지 않는다. 쉼표, "및", "와/과".
- 금액은 원, 만원, 억원. m, bn 같은 영어 단위는 쓰지 않는다.
- 연도는 '25, '26E(전망), '27P(계획)처럼 기준을 붙인다.
- 줄바꿈: 한 줄이 의미 단위로 끝나게 `\n`으로 직접 나눈다. 단어 중간 끊김과 마지막 줄에 어절 하나만 남는 외톨이 줄은 `check_text.py`가 잡는다.

## 5. 예시 (일반 사례)

| 밋밋하거나 구어체인 문장 | 덱 카피 |
|---|---|
| 고객 재구매율이 꾸준히 높게 유지되고 있습니다 | 고객 열 명 중 일곱이 다시 삽니다 |
| 다양한 채널을 통해 매출을 확대하고 있습니다 | 매출의 절반이 새 채널에서 나옵니다 |
| 한 번 만든 콘텐츠를 여러 시장에 또 팝니다 | 한 번 만든 콘텐츠가 시장마다 다시 매출이 됩니다 |
| 영업비용을 11개월이면 뽑습니다 | 고객 확보 비용은 11개월이면 돌아옵니다 |
