# 워딩 규칙 (공통)

어떤 문체로 쓰든 지키는 규칙이다. 문서 종류별 문체는 따로 고른다.
- 내부 검토자료, 보고서, 메모: `문체_검토보고.md` (개조식 실무체)
- 대외 서신, 투자자 안내문, 메일, 공식 설명문: `문체_서술형.md` (서술식 경어체)

이 파일과 문체 파일은 wording 스킬이 코덱스에게 함께 보낸다. 각 파일의 「## 코덱스에게 전달할 규칙」 절의 `- ` 줄만 전달되므로, 그 절에는 규칙만 둔다.

---

## 1. 숫자와 사실

1. 원본에 없는 숫자, 사실은 만들지 않는다. 모르면 `[확인 필요: 무엇]`, 값 자리만 비면 `##`.
2. 모든 숫자는 근거(파일, 쪽, 셀)를 댈 수 있어야 한다. 작업 원고에는 `(출처: 파일 p.N)`을 붙이고, 남에게 주는 최종본에서는 뗀다.
3. 금액은 한국식 단위로 쓴다. `95.9m`, `1.6bn` 대신 `95,868,891원`, `9,587만원`, `16억원`. 표는 `(단위: 백만원)`처럼 단위 줄을 둔다.
4. 반올림은 사사오입(`Decimal ROUND_HALF_UP`). 파이썬 `round()`는 쓰지 않는다. 합계는 표 안에서 맞추고 반올림 해명은 쓰지 않는다.
5. 원문끼리 숫자가 다르면 임의로 맞추지 않고 각각 두고 알린다.

## 2. AI가 쓴 티를 지운다

| 쓰지 않는 것 | 대신 |
|---|---|
| 가운뎃점 나열 「제작·운영」, 조어 「매입·판매형」 | 「제작과 운영」, 「A, B」, 「A 및 B」, 문장으로 풀기 |
| 영어 단위, 영어 섞기 「95.9m」, 「YoY +12%」 | 「9,587만원」, 「전년 대비 12% 증가」 |
| 근거 없는 최상급: 최고, 유일, 압도적, 혁신적, 획기적, 세계적 | 사실과 수치 |
| 단정 미래 「~할 것입니다」, 「~할 것임」 | 「~할 계획」, 「~로 예상됨」, 「~로 전망됩니다」 |
| 「A가 아니라 B」 문형, 화살표(→)나 줄표(—)로 문장 잇기 | 평범한 문장, 쉼표, 괄호 |
| 「핵심:」, 「요약:」, 「참고:」 머리말, 이모지, ⚠️ | 지운다. 필요한 내용은 본문 항목이나 주)로 |
| 문장마다 **굵게** 강조 | 굵게는 표 합계에만. 본문 강조는 밑줄로 한 절에 1~3곳 |
| 본문 속 하이퍼링크, URL | 지운다. 법령은 괄호로: (자본시장법 제161조) |
| 딱딱한 직역투 「이식」, 「막는다」, 「차단」 | 「옮기기」, 「공유」, 「멈춘다」, 「걸러낸다」 |
| 작업 과정 설명 「결산자료로 작성하였습니다」, 「원장에서 역산」 | 쓰지 않는다. 기준 시점은 「○○ 현재 기준」 |
| 같은 접속어로 연달아 시작 「또한」, 「특히」, 「이러한」 | 생략하거나 문장 합치기 |
| 한 문서 안에 개조식과 서술식 섞기 | 문서 종류에 맞는 문체 하나로 통일 |

내보내기 전에 `grep -c "·" 파일`이 0건인지 본다. 코덱스 결과에도 다시 들어올 수 있으니 워딩 뒤 한 번 더 본다.

## 3. 표식

| 상황 | 표식 | Word에서 |
|---|---|---|
| 값만 없음 | `##` (날짜 `##.##`) | 노란 형광 |
| 무엇이 없는지 밝혀야 함 | `[확인 필요: ○○]` 짧게 | 노란 형광 |
| 검토 의견, 사실 의심 | `[메모: …]` | Word 메모 |

사용자가 채우거나 확인할 곳은 반드시 노란색이다.

## 4. 밖으로 나가는 파일

- 제출용 Word, 엑셀 안에 출처 표기, 파일명, 쪽수, 시트명을 남기지 않는다.
- 엑셀은 사람이 만든 것처럼: Arial 9, 머리글 회색(D9D9D9) 검정 굵게, 소계 연회색(F2F2F2), 회계 서식. 강조색과 긴 주석 금지. 내부 검증 시트는 별도 파일로.
- 주민번호, 개인 휴대전화, 개인 계좌번호는 옮기지 않고 알린다.

---

## 코덱스에게 전달할 규칙

- 숫자, 날짜, 금액, 비율, 고유명사, 법령명과 조항 번호는 한 글자도 바꾸지 않는다.
- [확인 필요: …], (출처: …), ##, [메모: …] 표식은 글자 하나 바꾸지 말고 같은 자리에 둔다.
- 가운뎃점(·)으로 단어를 나열하거나 붙이지 않는다. 쉼표, "및", "와/과"로 쓴다.
- "A가 아니라 B" 문형, 화살표(→), 줄표(—)로 문장을 잇지 않는다.
- 최고, 유일, 압도적, 혁신적, 획기적, 세계적 같은 근거 없는 최상급을 쓰지 않는다.
- "핵심:", "요약:" 같은 머리말과 이모지를 쓰지 않는다. 굵게 강조를 새로 넣지 않는다.
- "이식", "막는다", "차단" 같은 딱딱한 직역투 대신 "옮기기", "공유", "멈춘다", "걸러낸다"처럼 평범한 말을 쓴다.
- 원문에 없는 원인, 평가, 전망을 보태지 않는다. 시제와 확신의 정도는 원문 그대로 둔다.
- 표를 소개하는 "다음과 같습니다" 문장이나 작업 과정 설명을 새로 만들지 않는다.
- 금액을 m, bn 같은 영어 단위로 바꾸지 않는다.
- "또한", "특히", "이러한"으로 시작하는 문장을 연달아 쓰지 않는다.
