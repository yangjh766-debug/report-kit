# 상장예비심사신청서 작성 플레이북 (범용)

코스닥 상장예비심사신청서를 회사 자료로 작성할 때, 한 번의 실제 작업에서 정리한 방법과 규칙을 **다른 회사에 그대로 다시 쓸 수 있게** 옮긴 문서 묶음이다. 특정 회사의 이름, 사람, 숫자, 제품은 들어 있지 않다.

- 전용 도구(스킬, 외부 AI 연결, 미리 만든 스크립트)가 없어도 된다. 문장 다듬기용 워딩 스킬은 같은 저장소의 report-kit 플러그인에 들어 있으니, 코덱스에 로그인할 수 있으면 설치해 쓴다. 사람이 직접 하거나, 일반 AI 도우미(Claude, ChatGPT 등)에게 이 폴더를 주고 시키면 된다.
- 자동화가 필요하면 `09_도구_레시피.md`의 짧은 파이썬을 복사해 쓴다.
- md 파일은 VS Code에서 열고 `Cmd+Shift+V`(윈도 `Ctrl+Shift+V`)로 미리보기를 켜면 표가 보인다. 순서도 그림은 `순서도.html`을 브라우저로 연다(인터넷 연결 없이 열린다).

---

## 처음 시작할 때 (첫 주)
1. `순서도.html`로 전체 흐름을 본다(5분).
2. `01_착수_및_작업흐름.md` 2절 「착수 첫날 할 일」대로 사용자(책임자)에게 확인할 것을 한 번에 묻고, 작업 폴더를 만든다.
3. `05_회사자료요청.md` 3절 「첫 요청 기본 세트」를 회사에 맞게 고쳐 첫 자료요청을 보낸다.
4. 자료가 오면 `02_자료가공_검증.md` 순서로 추출 → 대조표 → 검증을 한다.
5. 장을 쓸 때 `07_장별_체크포인트.md`의 그 장 절, 표는 `03_표서식.md`, 문장은 `04_문장_워딩.md`를 본다.
6. 사용자나 회사가 docx를 직접 고치기 시작하면 `06_docx_피드백루프.md`로 넘어간다.
7. 매 판을 넘기기 전에 `08_실수사례_교훈.md`의 「다음 회사에서 처음부터 할 것」을 확인한다.

## 이 플레이북의 한계
- **Ⅳ장(사업의 내용)은 원래 작업에서 다른 팀이 썼다.** 07 문서의 Ⅳ 절은 거래소 양식의 기재상의 주의와 필요 자료만 정리했고, 경험에서 나온 체크포인트는 없다.
- Ⅸ장(상장주선인의 종합의견)은 주관사가 쓰는 장이라 다루지 않는다. Ⅷ장도 공모 조건은 주관사와 협의가 필요하다.
- 거래소 양식이나 심사 실무 해설서가 개정되면 해당 규칙을 다시 확인한다.
- 예시는 모두 가상(㈜○○, 최대주주 A, YYYY.MM.DD)이다.

## 가장 중요한 원칙 다섯 가지
1. 원본에 없는 숫자와 사실은 만들지 않는다. 모르면 노란 `##` 또는 `[확인 필요: …]`로 두고 회사에 요청한다.
2. 숫자는 대조표 엑셀에서 재계산으로 검증한 뒤에 초안에 쓴다. 출처는 엑셀과 초안 md에만 두고, 제출용 docx에는 남기지 않는다.
3. 사용자, 회사가 고친 것, 다른 팀이 맡은 장은 건드리지 않는다. 판마다 칸 단위로 전후를 대조한다.
4. 표는 양식과 과거 신청서의 열 구성을 따르고, 글자 크기는 줄이지 않는 쪽으로 맞춘다.
5. 회사 자료는 기밀이다. 외부 저장소에 올리지 않고, 개인정보는 옮기지 않는다.
