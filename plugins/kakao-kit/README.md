# kakao-kit: 카톡 비서

맥 카카오톡 대화를 평일 근무시간에 1시간마다 읽어서, 대시보드 한 장에 정리해 주는 Claude Code 플러그인입니다. 카톡은 보내지 않습니다.

## 무엇이 나오나

`카톡비서.html` 한 파일에 아래가 모입니다.

| 칸 | 내용 |
|---|---|
| 답장할 것 | 나에게 묻거나 부탁한 메시지와 바로 쓸 답장 초안, 복사 버튼 |
| 할 일 | 대화에서 뽑은 내 할 일과 마감. 연락할 일은 초안, 직접 할 일은 하는 방법 |
| 받은 파일 | 카톡에서 저장한 문서의 내용 요약 |
| 일정 | 날짜와 시간이 분명한 약속을 Google 캘린더에 넣은 기록 |
| 시간대별 요약 | 업무방은 자세히, 개인 대화는 한 줄로 |

카톡으로 답했거나 끝난 일은 다음 실행 때 자동으로 완료 표시됩니다.

## 설치

```
/plugin marketplace add yangjh766-debug/report-kit
/plugin install kakao-kit@report-kit
```

설치한 뒤 Claude Code 에 "카톡 비서 설치해 줘"라고 하면 스킬이 순서대로 안내합니다. 직접 해야 하는 일은 맥 시스템 설정에서 실행기 한 파일에 전체 디스크 접근 권한을 주는 것 하나입니다.

필요한 것: 맥 카카오톡(로그인 상태), Claude Code, Homebrew, Xcode 명령줄 도구. Gmail 과 캘린더 커넥터, 코덱스는 있으면 씁니다.

## 안전장치

- **보내기 없음**: 카톡을 읽는 kakaocli 에서 보내기, 로그인, 동기화 명령을 지우고 빌드합니다. 화면 조작으로 보내는 도구는 받지 않습니다.
- **카카오 서버에 접속하지 않음**: 대화와 첨부는 맥에 있는 것만 읽고, 그 단계는 인터넷을 끊은 상태로 돕니다.
- **Claude 권한 최소화**: 요약하는 Claude 는 그 시간의 첨부 폴더 읽기, Gmail 임시보관함 초안, 캘린더만 쓸 수 있습니다.
- **가림**: 비밀번호, 인증번호, 주민번호는 Claude 에 넘기기 전에 가립니다.

## 미리 알아 둘 것

- 카카오가 공식 지원하는 방식이 아닙니다. 계정 이용 제한 가능성이 0이라고 말할 수 없습니다.
- 새 메시지 본문은 요약을 위해 Claude(Anthropic)로, 답장 초안은 코덱스(OpenAI)로 갑니다.
- 상대방 메시지도 함께 처리됩니다. 내 업무 정리용으로만 쓰고, 다른 사람의 대화를 모으는 데 쓰지 마세요.
- 사진은 카톡 앱이 암호화해 저장하므로 내용을 읽지 않습니다. 문서는 카톡에서 한 번 저장해 두면 읽습니다.
