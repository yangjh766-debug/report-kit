# 메일 자동화 가이드 (Aside, ChatGPT, Claude)

2026년 10월 기준으로 확인한 내용이다. 기능이 자주 바뀌니 설정 화면 이름은 조금 다를 수 있다.

## 0. 먼저 정할 것: 어디까지 자동으로 보낼까

| 단계 | 내용 | 권장 |
|---|---|---|
| 1단계 | AI가 받은편지함을 읽고 요약, 분류 | 바로 자동화 |
| 2단계 | AI가 답장 초안을 만들어 임시보관함에 넣음 | 바로 자동화 |
| 3단계 | 사람이 초안을 보고 [보내기] | 대부분의 업무 메일 |
| 4단계 | AI가 사람 확인 없이 발송 | 내부 정기 보고, 정해진 양식의 알림만 |

외부 거래처, 투자자, 계약 관련 메일은 3단계에서 멈춘다. 잘못 나간 메일은 되돌릴 수 없다.
4단계를 쓸 때는 받는 사람을 고정 목록으로 묶고, 처음 2주는 나에게 숨은참조(BCC)로 오게 해 결과를 본다.

## 1. 도구별로 되는 것

| | Aside | ChatGPT (Gmail 앱) | Claude (Gmail 커넥터) | Google Apps Script |
|---|---|---|---|---|
| 메일 읽기, 검색, 요약 | 됨 | 됨 | 됨 | 됨 |
| 답장 초안 | 됨 | 됨 | 됨(임시보관함에 저장) | 됨 |
| 발송 | 됨(발송 전 확인 창) | 됨(**보낼 때마다 승인 필요**) | 안 됨(초안까지) | 됨(완전 자동) |
| 예약 실행 | 루틴 | 예약 작업(Scheduled tasks) | Claude Code `/schedule` | 시간 트리거 |
| 메일 도착 시 실행 | 루틴(조건 감시) | 이벤트 작업(Plus 이상) | 없음 | 트리거로 주기 확인 |
| 로그인된 웹사이트 조작 (그룹웨어, ERP) | **됨** | 에이전트 모드로 일부 | 컴퓨터 사용으로 일부 | 안 됨 |

## 2. Aside로 메일 자동화

Aside는 AI가 직접 조작하는 크롬 계열 브라우저다. 내가 로그인해 둔 사이트(Gmail, 그룹웨어, 은행 조회 화면)를 AI가 대신 쓴다. 모델은 Claude 구독을 연결해 쓸 수 있다.

**설치**
1. aside.com에서 맥용 앱을 내려받아 설치하고 실행한다.
2. 처음 실행 때 계정을 만들고, 모델 제공자로 Claude Code(내 Claude 구독)를 고른다.
3. Aside 브라우저 안에서 Gmail에 로그인한다. 회사 그룹웨어도 여기서 로그인해 둔다.
4. 손쉬운 사용, 화면 기록 권한을 묻으면 허용한다(맥 시스템 설정 → 개인정보 보호 및 보안).

**써 보기**
- 새 탭 옆 패널에 한국어로 시킨다: 「받은편지함 정리하고 답장이 필요한 메일만 초안 써 줘」
- Gmail은 탭을 열지 않고 내부 기능으로 읽는다. 여러 구글 계정이 있으면 어느 계정인지 말해 준다.
- 발송, 결제, 게시 같은 민감한 행동은 실행 전에 확인을 묻는다.

**루틴(자동 실행) 만들기**
- 패널에 이렇게 말하면 루틴으로 만들어 준다:
  - 「평일 아침 8시에 받은편지함에서 거래처, 투자사 메일만 골라 요약하고 답장 초안을 임시보관함에 넣어 줘」
  - 「○○님에게 매주 금요일 오후 5시에 주간 자금 현황 메일을 보내 줘. 첨부는 ○○ 폴더의 최신 엑셀」
  - 「'계약서', '견적' 단어가 든 메일이 오면 첨부를 내려받아 ○○ 폴더에 저장하고 알려 줘」
  - 「내가 보낸 메일에 3일간 답이 없으면 팔로업 초안을 만들어 줘」
- 루틴 목록과 실행 기록은 Aside의 작업(Tasks) 화면에서 본다. 처음 몇 번은 결과를 직접 확인한다.

**실제 사례(이 팩 작성자)**
- Gmail 112건을 읽고 답장이 필요한 1건만 추려 초안을 받음.
- 회사 그룹웨어(더존 아마란스)에 로그인해 회계 전표 입력 화면까지 들어가 테스트 전표를 넣고, 전자결재 미결 문서를 조회함.
  주의: 시험 삼아 넣은 전표는 실제로 저장된다. 테스트 후 반드시 지운다. 실제 업무는 「입력만 하고 저장 전 화면을 보여 줘」로 시작한다.

**Claude Code와 연결 (선택)**
```bash
curl -fsSL https://releases.aside.com/install.sh | bash   # Aside CLI 설치
aside login
aside host list            # 내 맥이 online으로 보이면 정상
aside skills install       # Claude Code, 코덱스에 'Aside 브라우저 쓰는 법' 스킬 설치
aside mcp                  # MCP 서버로 붙일 때
```
설치하면 Claude Code에서 「Aside로 그룹웨어 들어가서 이번 달 미결 결재 목록 뽑아 줘」처럼 시킬 수 있다.

## 3. ChatGPT에 Gmail 연결

1. chatgpt.com → 왼쪽 아래 내 이름 → 설정(Settings) → 앱(Apps, 예전 이름 커넥터) → Gmail → 연결.
2. 구글 로그인 창에서 권한을 허용한다.
3. 대화창 + 버튼에서 Gmail을 켜고 시킨다: 「어제 온 메일 중 답장할 것만 골라 초안 써 줘」
4. 발송: 「이 초안 ○○님께 보내 줘」라고 하면 보내기 전 확인 창이 뜨고, 승인하면 내 Gmail로 나간다.

**예약 작업 (Scheduled tasks)**
- 「매일 아침 8시에 지난밤 온 메일을 요약해 줘」라고 하면 예약 작업이 된다. 결과는 ChatGPT 알림과 메일로 온다.
- 예약 작업은 읽기, 요약, 초안까지 자동이다. **발송은 사람 승인이 필요하다.**

**메일이 오면 실행 (이벤트 작업)**
- Plus 이상 요금제. Work(업무) 화면에서 「○○ 도메인에서 메일이 오면 내용을 요약하고 답장 초안을 만들어 줘」처럼 조건과 할 일을 쓴다.
- ChatGPT가 보여 주는 트리거, 조건, 할 일을 확인하고 저장한다. 조건에 맞는 메일을 나에게 보내 시험한다.
- 한도: 시간당 30회, 하루 720회. 동시에 켤 수 있는 작업 수는 요금제마다 다르다(Plus 5개).

## 4. 사람 확인 없이 보내야 할 때: Google Apps Script

정해진 사람에게 정해진 양식으로 보내는 메일(주간 보고, 마감 알림)은 AI보다 스크립트가 안전하다. 매번 똑같이 동작하기 때문이다.

1. script.google.com → 새 프로젝트 → 아래 코드 붙여넣기 → 받는 사람, 시트 주소만 바꾼다.
2. 왼쪽 시계 모양(트리거) → 트리거 추가 → `sendWeekly`, 시간 기반, 매주 금요일 오후 5~6시.

```javascript
function sendWeekly() {
  const to = "team@example.com";                       // 받는 사람(고정)
  const sheet = SpreadsheetApp.openById("시트ID").getSheetByName("요약");
  const rows = sheet.getRange("A1:D10").getDisplayValues();
  const html = "<table border=1 cellpadding=4>" +
    rows.map(r => "<tr>" + r.map(c => "<td>" + c + "</td>").join("") + "</tr>").join("") + "</table>";
  GmailApp.sendEmail(to, "[주간] 자금 현황 " + Utilities.formatDate(new Date(), "Asia/Seoul", "MM/dd"),
    "HTML 메일입니다.", { htmlBody: html, bcc: Session.getActiveUser().getEmail() });
}
```

Claude Code에 「이 시트를 매주 금요일에 메일로 보내는 Apps Script 써 줘」라고 하면 위 같은 코드를 만들어 준다.

## 5. 추천 조합

- **매일 아침**: ChatGPT 예약 작업 또는 Aside 루틴으로 받은편지함 요약 + 답장 초안. 나는 초안만 보고 보낸다.
- **문서가 붙는 메일**: Claude Code로 보고서, 엑셀을 만들고 `/wording`으로 문장을 다듬은 뒤, Gmail 초안으로 저장. 내가 보낸다.
- **정기 고정 메일**: Apps Script로 완전 자동.
- **그룹웨어, ERP 작업**: Aside. 저장 전 화면 확인을 습관으로.
